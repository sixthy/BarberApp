# Barbershop API

Backend NestJS da aplicação de barbearia.

## Rodar localmente

```bash
npm install
npm run start:dev
```

## Build de produção

```bash
npm run build
npm run start:prod
```

## Variáveis de ambiente

Copie `.env.example` para `.env` no ambiente local e configure:

- `PORT`
- `MONGODB_URI`
- `FRONTEND_URLS`
- `JWT_SECRET`
